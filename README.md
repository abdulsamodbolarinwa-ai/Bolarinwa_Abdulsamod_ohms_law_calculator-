# Bolarinwa_Abdulsamod_ohms_law_calculator-
⚡ Ohm's Law and Power Calculator

Project Overview

The Ohm's Law and Power Calculator is a Python-based mini project developed by an ND1 Mechatronics student. It calculates voltage, current, resistance, and electrical power using basic electrical formulas.

Objectives

- Apply Python programming to electrical engineering.
- Understand the practical application of Ohm's Law.
- Improve problem-solving and programming skills.

Features

- Calculates voltage, current, resistance, and power.
- Provides a simple menu for users.
- Displays previous calculations.
- Handles invalid inputs and division by zero.

Additional Feature

Calculation History: Stores previous calculation results and allows users to view them again.

Python Concepts Used

- Functions
- Loops
- Conditional statements
- User input and float conversion
- Lists
- Exception handling

Formulas

- Voltage: V = I × R
- Current: I = V ÷ R
- Resistance: R = V ÷ I
- Power: P = V × I

How to Run

1. Install Python.
2. Open the Python file in VS Code or IDLE.
3. Run the program.
